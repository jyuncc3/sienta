Google Sheets (雲端試算表) 同步設定

本網頁可直接與您的 Google 試算表達成雙向極時同步。我們不把你的連結暴露在程式碼中，而是使用你剛才設定的「安全密碼」在你的手機本地加密保存。確保駭客或第三方無從得知！

步驟 1：建立試算表

建立一個全新的「Google 試算表」，並在第一列(標頭)依序填上：加油日期、行駛當下里程、一公升油價、加油公升數。

步驟 2：開啟擴充指令碼

在試算表上方選單，點選「擴充功能」 ➡️ 「Apps Script」。

步驟 3：貼上連接程式碼

清空裡面原有的程式碼，複製並貼上下方這段程式碼：

function doGet() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  var result = [];
  for (var i = 1; i < data.length; i++) {
    var row = data[i];
    if(!row[0]) continue;
    var rawDate = row[0];
    var formattedDate = "";
    if (rawDate instanceof Date) {
      formattedDate = Utilities.formatDate(rawDate, Session.getScriptTimeZone(), "yyyy-MM-dd");
    } else {
      formattedDate = String(rawDate).split('T')[0];
    }
    result.push({
      date: formattedDate,
      mileage: Number(row[1]),
      price: Number(row[2]),
      liters: Number(row[3])
    });
  }
  return ContentService.createTextOutput(JSON.stringify(result)).setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  sheet.clearContents();
  sheet.appendRow(["加油日期", "行駛當下里程", "一公升油價", "加油公升數"]);
  var payload = JSON.parse(e.postData.contents);
  for (var i = 0; i < payload.length; i++) {
    var r = payload[i];
    sheet.appendRow([r.date, r.mileage, r.price, r.liters]);
  }
  return ContentService.createTextOutput(JSON.stringify({status: "success"}))
    .setMimeType(ContentService.MimeType.JSON)
    .setHeaders({"Access-Control-Allow-Origin": "*"});
}

步驟 4：部署為網頁應用程式

點選右上角「部署」➡️「新增部署」。在左上角齒輪選擇「網頁應用程式」，並確保設定：
• 執行身分：「我」 (Me)
• 誰有權限存取：「任何人」 (Anyone)。
點擊部署，並在彈出的授權中允許存取試算表。複製最後生成的「網頁應用程式 URL」，貼到最上方的輸入框即可完成！
